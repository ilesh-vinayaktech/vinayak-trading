# Forecast data and statistics audit, 2026-11-18

> **Disclosure (added in review).** The ablation and the period comparison below were run on all 1,678 days through 2026-11-16, which **include the accessed 2025-2026 period**; the 7-feature candidate was
> chosen after seeing them, so its choice was informed by accessed data. A development-only replication (fit and score on days to 2024-12-31, 1,212 days) is in `candidate_morning7_disclosure.md`; it points the same way.

Checked against the validation spec (phases 1 and 2). Evidence is from the code and the database; the full evaluation is in `evaluation_2026-11-18_h1.md`
(`scripts/evaluate_forecast.py`).

| Spec point | Finding | Status |
|---|---|---|
| 3.3 A missing figure became a number | Confirmed. A missing overnight figure was filled with 0, a missing zone signal or fear/greed score with 50, a missing sector return with 0, no advance/decline count with 50. | Fixed. Missing stays missing; the model fills it from its **training rows only** (so it neither pushes nor is named as a reason). A morning forecast is not made at all when the US figures are not in. Not done: an explicit missing-value indicator column (no feature is missing often enough to matter yet). |
| 3.4 Night and morning were one product | Confirmed. One record and one model version held both; the morning run **overwrote** the night's row for the same day; the walk-forward record (58.9%) used the US inputs, which the night forecast cannot see (the US session closes at about 02:30 IST). | Fixed. Two products, `logit-v2-night` (no overnight inputs) and `logit-v2-morning`, each with its own model, record and walk-forward history. The page shows the morning forecast once it exists and each product's own record. |
| 3.5 Predictions overwritten, evidence not kept | Confirmed (live rows were rewritten; one version string covered three feature sets). | Fixed for live predictions: written once, never replaced. Each row now keeps `made_at`, the feature values as seen (null where missing) and `train_through`. Walk-forward rows are still replaced on a rebuild, because they are re-derivable from the data; a new model version writes new rows. Not stored per row: the full training-set size. |
| 3.2 Survivorship | Confirmed as a limit. Stocks with bars rise from 1,267 (2016) to 2,637 (2026) and only 20 of 2,658 instruments are marked delisted: the breadth universe before the NSE bars begin (Oct 2019) is survivors only, and delisted stocks are mostly missing after it too. Liquidity eligibility is point-in-time (20-day traded value on each day). | **Open.** Cannot be fixed without the delisted stocks' bars (NSE legacy bhavcopy is not loaded). Effect on the forecast: the evaluated days start in 2020, and the zone signals are not what carries the forecast (see ablation). |
| 3.1 Look-ahead | Zone signals use only earlier days; walk-forward uses only outcomes known by then; US returns use only sessions that closed before the Indian open. The FII participant file's publication time is **not proven** to precede 21:45 IST (we do not store when NSE posted it). | Ablation: removing FII positioning (or gold) does **not** lower the forecast's skill (+0.0322 with, +0.0326 without), so the risk does not affect the result. |
| 5.1 GIFT history | The spec says it begins Dec 2024. Stored 08:45 readings begin **2024-01-01** (743 days); Kite daily candles reach back to 2021-06 and minutes about two years. | Correct the record; GIFT is still not a model input. |

## Ablation (morning model, 1 day, same 1,678 days)

| Inputs | Accuracy | Brier skill vs usual tendency |
|---|---|---|
| All 18 features | 58.9% | +0.0322 |
| Without FII positioning | 59.0% | +0.0326 |
| Without gold | 58.8% | +0.0353 |
| Without FII and gold | 59.4% | +0.0357 |
| **US overnight + price returns + share rising only (7 features)** | **61.1%** | **+0.0481** |
| Without US overnight | 54.4% | -0.0091 |

The zone signals add noise to the day-ahead forecast; the US overnight moves carry it. The 7-feature variant was chosen after seeing these results, so it is a
**research candidate, not a promotion**: it is ahead in 2020-21, 2022-23 and 2024-26, but each gap to the 18-feature model has a 95% interval that touches zero.
Skill has also faded: 2024-2026 is only +0.006 (18 features) / +0.018 (7 features), against +0.09 in 2022-23 (**that 2024-2026 figure includes the accessed 2025-2026 period**; for development data only, see `diagnosis_2026-11-18.md`: 2024 alone is -0.008).
